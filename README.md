# TinyDistro (TinYdIStro)

TinyDistro is a minimal Linux distribution
designed for learning, development, and
custom system building.

It uses a lightweight initramfs-based design
with a separated Linux kernel and root filesystem.

The system contains:

- vmlinuz: standalone Linux kernel image
- initramfs.img: compressed root filesystem

TinyDistro focuses on simplicity, portability,
and giving users full control over their Linux
environment.

The root filesystem is small and customizable.
Users can extract, modify, rebuild, and create
their own versions of the system.

TinyDistro includes:

- Toybox userspace utilities
- glibc compatibility
- runit service supervision
- Linux kernel support

The distribution can run inside QEMU and can
be adapted for different hardware platforms.

Users can compile custom kernels, add drivers,
enable graphics support, networking, VNC,
or create specialized environments.

TinyDistro is made for developers, researchers,
students, and Linux enthusiasts.
